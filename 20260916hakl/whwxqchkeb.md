# 家长注意啦！夏季警惕儿童手足口病

> 更新时间：2026-09-16 (UTC+8)

**护理科普83  **

最近天气慢慢变热，病毒也活跃开了。家里有上幼儿园的宝妈们，要注意了，手足口病要来了！！！如果您发现宝宝的手、脚、口腔、屁股，起了一些小疱疹，而且发烧，不想吃东西，很可能是感染手足口病了。

手足口病传染性很强，传播途径主要为粪口传播、飞沫传播或密切接触传播。所以幼儿园的小朋友发病率最高，班里有一个小朋友生病了，其他的小朋友可能都会被传染上。如果在家里发现您的宝宝有上述这些症状，就不要送宝宝去幼儿园了，在家好好休息。

手足口病虽然传染性强，但它是自愈性疾病，所以宝妈们先不要惊慌，基本上一周左右症状就可消退，两周后就可以去幼儿园了。手足口病发病初期一般会发热，要密切监测宝宝的体温变化，及时采取物理降温或者药物降温。鼓励宝宝多饮水，以补充高热消耗的水分。如果宝宝的口腔有疱疹，他可能会不愿吃饭，宝妈要把食物做的软烂，晾凉一些后再吃，饭后可以用生理盐水漱口，保持口腔的清洁。手、脚、屁股上的疱疹一般是不会留疤的。尽量看好宝宝不要抓破，如果不小心疱疹破了，有感染的迹象，可局部涂抹抗生素软膏。

手足口病多数是轻症，在家护理就可以痊愈。但是也会有很少一部分会发展成重症，重症就必须要去医院治疗了。如果宝宝出现精神差、嗜睡、易惊、头痛、呕吐、四肢抽搐等症状就要立即送宝宝去医院，积极配合医生治疗。

**目前对于手足口病，没有特效的抗病毒药物。日常生活中我们的预防就尤为重要了。**

1.勤洗手：要养成良好的卫生习惯，勤洗手。饭前便后、尤其是在外出回家后，要用流动的清水和洗手液，清洗双手。

2. 勤消毒：宝宝的日常用品、玩具都要定期清洁、消毒，奶瓶、餐具等煮沸消毒，衣物、被褥要在太阳下晾晒。

3. 勤通风：保持家庭环境卫生，居室要勤开窗通风，保持空气流通。

4. 多喝水：日常生活中，要多补充水分，不喝生水，不吃生冷食物。

5.适量的运动：保持适量的运动，可以提高宝宝的免疫力。

6.减少接触：避免接触患病的宝宝，流行期间尽量不要去拥挤的公共场所。
