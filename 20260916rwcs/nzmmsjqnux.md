# 成都市妇女儿童中心医院就诊告知书

> 更新时间：2026-09-16 (UTC+8)

为积极落实国家对新型冠状病毒感染肺炎疫情防控工作的部署，全面落实我省突发公共卫生事件一级响应；全力保障母婴安全、守护儿童健康，为妇女儿童提供安全有序的就医环境，特向来我院就诊的病友及家属做如下告知：

**01**

**配合预检：**

请来院就诊的病友及家属自觉按要求佩戴口罩，主动经过体温检测通道后进入院区。

**02**

**据实告知：**

发病前两周内有武汉生活或接触史的就诊者，请主动如实告知医院预检分诊处及接诊医生，并做好个人自我防护。

**03**

**就诊须知：**

1. 产科

门诊正常开诊：做好防护，及时产检。产检的准妈妈请按时检查。

2. 妇科、儿科

危急重症患者，请及时来院就医。

非危急重症患者请拨打医院咨询电话：028-63806390进行电话咨询。

3. 发热门诊24小时开放，为避免交叉感染，发热患者，经预检分诊、挂号后到指定区域就诊。

4. 来院就诊，请做好自我防护措施（自觉佩戴口罩）按要求进入就诊区域，尽量减少陪护人员。

**04**

**咨询服务：**

为方便母婴及时安全的母乳喂养，避免交叉感染，医院电话18086842430，每周一、周三、周五（8:30-17:00）由专家为妈妈们免费提供母乳喂养咨询服务，陪您走过特殊时期的母乳喂养。

      祝：健康平安！
