# 八珍丸的功效与作用(桃红四物汤功效与禁忌)

> 更新时间：2026-09-19 (UTC+8)

八珍丸的功效与作用？那本文就这个问题以桃红四物汤功效与禁忌为大家详细介绍一下。

**八珍丸的功效与作用**

八珍丸的配方里主要有熟地黄、当归、党参、白术、白芍、川芎、甘草等，因为这几味中药主要起到补血、活血、养血营卫、止血行气、祛风止痛等作用，所以八珍丸有补气养血的功效与作用。八珍丸成分复杂，所以在服用时是需要注意一些禁忌以及不适宜人群的，像孕妇、哺乳期妇女、儿童及年老体虚者要禁止服用，而适用人群就是气血两虚，面色萎黄，食欲不振患者等。

**八珍丸的功效与作用**

八珍丸主要功效是补气血，活血祛瘀，用于治疗气血虚弱，瘀血引起的月经不调，身体无力，四肢无力，头晕心慌，食欲不振，面色萎黄等疾病。

**八珍丸适用人群**

八珍丸适合气血两虚的女性患者服用，效果不错，所谓气血两虚一般出现在贫血、白细胞减少症、血小板减少症、大出血后、妇女月经过多者等。患有心脏病、肝病、高血压等慢性病情况较为严重者也能服用，但是因身体特殊，建议最好是在医生的指导下用药。

**八珍丸的禁忌**

1. 服用八珍丸期间，不宜食用腥辣的食物；

2. 过敏体质者、感冒发热患者慎用八珍丸；

3. 孕妇、哺乳期妇女、儿童及年老体虚者都要慎用八珍丸；

4. 八珍丸为气血双补之药，本身的性质较粘腻，服用后可能会对消化功能有所影响，易导致纳食不消，所以建议的是腹胀便溏者忌服。

目前观察发现的八珍丸不良反应尚不明确，所以说，在使用这个药物的时候，一定要在医生指导下服用。该药功效比较多，适用人群也挺多，但是还是要特别的注意一些禁忌。

**桃红四物汤功效与禁忌**

桃红四物汤主要由当归、熟地、川芎、白芍、桃仁、红花这6种中药材组成，具有抗炎、祛斑养颜、养血活血、降脂、补充微量元素的功效和作用，也是女性日常中常用的调经中医方剂之一。但并非所有人都能喝，因为它是有禁忌的，比如说高血压、高血糖的患者不适合喝桃红四物汤，怀孕期间的女性也不能喝，同时该中药方也不能每天都服用。

**桃红四物汤功效**

桃红四物汤的配方主要由四物汤演化而来，主要加了桃仁和红花两味药材，而这两种中药都具有破血行瘀和润燥滑肠的功效。桃红四物汤还具有以下功效：

1. 桃红四物汤能祛斑，因为这个汤里面的白芍有着养肝的好处，有斑的原因主要是因为肝的代谢功能虚弱了，而一般产后形成的斑就可以通过喝四物汤调理；

2. 治疗黄褐斑，中医认为黄褐斑的产生原因是由于肝肾精血两亏所致，而桃红四物汤就是专门治疗气血两亏的疾病；

3. 常喝桃红四物汤能帮助扩张豚鼠离体心脏冠状动脉，从而增加冠脉血流，喝该汤剂具有降低血管阻力的好处；

4. 桃红四物汤中含有钠、镁、磷、硫等人体所必须的微量元素，适量的喝可以帮助人们补充这些微量元素，强健身体。

常期喝桃红四物汤除了以上的好处外，对于经前症状如乳房不适、心情焦虑及沮丧等能有很好的调节，同时它还具有治疗冠心病心绞痛、痛经、女性更年期综合征、眼底出血等病症的作用。

**桃红四物汤禁忌**

1、非血瘀体质者不能服用桃红四物汤，因为它是一道调理血瘀体质的方子，如果你是单纯血虚体质的话，那么可以通过服用传统的四物汤来进行调理；

2、一些偏实热阴虚内热的女性也不宜服用桃红四物汤，因为“四物汤”本身偏温，再喝四物汤容易上火、长痘痘；

3、经期的时候也不能喝四物汤，由于四物汤具有凉血滋润的作用，所以一些高度贫血和肠胃虚弱易腹泻者也不宜服用；

4、出现感冒、发炎等症状的人也不宜服用，如此这期间再继续喝桃红四物汤，那么将会导致发炎肿胀更剧烈，所以遇到感冒时要停止再继续喝。

还有就是桃红四物汤不能天天喝，持续喝的话会造成经血过多、呼吸喘促等情况。因为每个人的体质是不一样的，所以喝桃红四物汤最好咨询专业的中医生。
