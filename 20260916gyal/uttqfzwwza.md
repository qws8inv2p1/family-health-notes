# 战“疫”党旗红——南宁市第二人民医院抗“疫”先锋系列报道（三）

**不忘初心、我心向党**

**善良的你，****医者的心。**

 一个党员，一面旗帜。医院党委发出招募志愿者倡议后，医院立即组织了一线志愿者，报名参战一线的医护人员，大部分是中共党员，在这些党员的引领带动下，共有30名在职职工向党组织火线提交入党申请书。

**战地临时党支部书记**
覃丽颖，南宁市第二人民医院重症监护室护士，内科第五党支部组织委员，驰援湖北医疗队护理组组长兼临时党支部书记。

作为一名拥有九年重症护理经验的护士，在得知医院组织驰援武汉医疗队的消息后，第一个、第一时间向党委和护理部递交请战书，强烈要求前往湖北一线驰援。在得知院党委成立驰援湖北医疗队临时党支部的消息后，主动要求担任临时党支部支部书记。“我们临时党支部支委出发前，已经召开了第一次支委会议讨论到了疫区如何发挥好支部堡垒作用，把二医院党建品牌精神带到前线去。只要党委号召，我们随时都可以出发！”覃丽颖和队员们出发前进行了疫情防护的培训，待命期间还努力练习护理操作，这样能尽快进入疫情的救护当中。     

**火线提交入党申请**

钟俊健，是神经外科的一名男护士，也是医院的文艺骨干积极分子。在医院党委发出招募志愿者的倡议后，他第一时间递交了驰援湖北的请战书。由于综合能力不错，医院把他选为此次驰援湖北医疗队的队员。他感到很光荣：“救死扶伤、医者天职，我身边有很多这样的榜样，像钟日胜、丁可这些先进人物的事迹影响着我，这次我自愿出征湖北抗击新型肺炎疫情，必将恪尽职守、勇于担当，守护生命，全力阻击疫情，完成好党和政府交给的任务。”

**中共党员必须上**

“您好，请测量一下体温，谢谢配合。”医院安保人员杨智高用体温枪仔细地检测每一个进入医院安检门的人员。虽然家在邕宁，过年期间他也没有回家，他和安保兄弟在警务室里度过了除夕。

“每天出入医院的人流量很大，为了照顾年长的，有家庭的安保人员，春节值班的人员安排都是年轻人，尤其是中共党员必须留守，大家都没有意见。”安保科科长平善满说，即使这样仍然有人主动放弃休假，队员黄益浩自女儿出生后，没有休产假，主动要求春节排班。罗秀斌，警察学院毕业，当过兵，目前担任医院备勤中队队长兼警务室组长，这个敢冲敢干的90后中共党员带头提出了“召必应、应必上”的要求。

自疫情爆发后，南宁市第二人民医院安保人员职责在安检保卫的基础上增加了一项内容：体温检测。安保协警队员节日期间24小时轮岗值班，对所有进入医院的人员进行体温检测排查。这是一支召之即来、来之必战、战之必胜的队伍，30名安保人员为全院干部职工筑牢第一道防线在请战书上集体按下了手印。
